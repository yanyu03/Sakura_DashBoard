# 本地运行与演示

## 环境

- 推荐 Node.js 24 LTS；`package.json` 最低要求 22.12。
- npm 与 Git。依赖版本以 `package-lock.json` 固定，使用 `npm ci`。
- 默认不需要云账户、数据库凭据、AI Key，也不读取作者桌面的配置文件。

`better-sqlite3` 是原生模块。若当前平台没有匹配的预编译包，需要该平台的 C++ 构建工具和 Python；优先使用支持的 Node LTS 与 x64 环境。不要使用禁用 TLS 校验作为安装或网络故障的解决办法。

## 安装与首次注册

```bash
git clone https://github.com/yanyu03/Sakura_DashBoard.git
cd Sakura_DashBoard
npm ci
npm run dev
```

入口：`http://127.0.0.1:3000/?design=1.0Sakura`。默认只监听 `127.0.0.1`，不会向局域网开放。

1. 进入 `/register?design=1.0Sakura`，填写用户名、邮箱、密码和图形验证码。用户名为 3–32 位字母 / 数字 / 下划线，密码至少 8 位；姓名可不填。
2. 空安装第一位注册者成为应用管理员，后续公开注册者为教师。这里的管理员不是操作系统 root，也不会自动获得学校所有岗位。
3. 进入 `/login?design=1.0Sakura` 登录。首次安装没有默认用户名或共享密码。
4. 用户名不可通过偏好页修改；偏好设置不能提升角色。

数据保存在 `.local-data/portfolio/sakura_edu.sqlite`。启动按顺序执行 v15 迁移，保留已有账号和业务；不会每次重置或补入演示教师。停止服务用 `Ctrl+C`。

## 更改端口或隔离演示数据

PowerShell：

```powershell
$env:PORT='3100'
$env:SAKURA_DATA_DIR='.local-data/my-portfolio-review'
npm run dev
```

macOS / Linux：

```bash
PORT=3100 SAKURA_DATA_DIR=.local-data/my-portfolio-review npm run dev
```

换一个新的数据目录即可得到独立空安装。不要把线上导出、学校真实资料或其他安装的数据库拷到演示目录；不要为重新体验而直接删除已有业务数据。根目录 `.env.example` 仅说明可用变量，当前入口不自动加载 `.env`。

## 建议的完整演示顺序

| 步骤 | 操作与观察 |
| --- | --- |
| 基础资料 | 管理员建立学期、课程、教师、班级、学生及实际任课关系；使用自造姓名和测试邮箱 |
| 组织配置 | 建立学校及所属组织，设置教师、班主任和负责人的有效任职；应用管理员需要单独任职才能演示教研室负责人 |
| 课表闭环 | 教师保存私人草稿 → 共享提交到教研室 → 另一位有效负责人批准 → 形成正式课时 |
| 权限对照 | 用不同浏览器配置文件登录无关教师，验证不能读取私人草稿、另一教研室提交或无关班级 |
| 作业与成绩 | 发布作业、登记及批阅正文；创建考试，下载 CSV 模板、预览再确认导入，观察零分与缺考的区别 |
| 故障与版本 | 两个页面修改同一记录，后保存的旧版本应得到 409；临时 API 故障不应把用户退出或显示假成功 |

同一浏览器的多个标签共享 Cookie，不能用它们证明两个账号隔离；请用不同浏览器配置文件或隐私窗口。

本地提供统一业务 API，SQL 管理路径返回 403。测试 SQLite 默认使用加强带盐哈希，生产 TiDB 则额外强制独立 pepper；本地 HTTP Cookie 不设置 Secure，仅用于回环开发。不要将此开发进程直接作为公网生产服务。

## 入口与命令的区别

| 命令 | 用途 |
| --- | --- |
| `npm run dev` / `npm run dev:portfolio` | 推荐：空安装、共享业务应用、本地 SQLite、Vite 开发界面 |
| `npm run dev:legacy` / `npm run dev:standard` | 历史演示入口，会生成原型样例；不作为首次注册或生产权限的验收入口 |
| `npm run build` | 编译前端静态产物，不启动 API 或数据库 |
| `npm run preview` | 只预览静态产物；单独运行无法验证登录 / 保存等 API |
| `npm start` | 旧 Node 服务入口，保留兼容用途；不是生产 Worker 的启动方式 |

## 常见问题

- **端口占用**：更换 `PORT`。已有 3000 端口预览不会被新进程接管。
- **注册后没有自动登录**：回到登录页完成验证码与认证，这是正常流程。
- **五次错误后不能继续尝试**：按页面冷却提示等待，不要反复提交；档位为 30 秒、1 分、2 分、15 分、3 小时。
- **列表为空**：新安装没有教学资料；先建学期、班级和任课关系，不能依赖截图里的演示数据。
- **生产环境失败而本地正常**：按 [部署手册](DEPLOYMENT.md) 核查 Secret、数据库权限、HTTPS 驱动、版本和健康检查，避免盲目重放保存请求。

验证脚本与是否需要外部凭据的完整分组见 [TESTING](TESTING.md)。
