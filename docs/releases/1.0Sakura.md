# 1.0Sakura · Engineering Preview

SakuraEdu 学校组织、教师协作与教学工作台的开源工程预览。代码及项目文档采用 MIT 许可，保留第三方来源说明与开发验证记录。

## 本次交付

- React / TypeScript 教学工作台与 1.0Sakura CSS 设计规范。
- 学校组织链、多岗任职、任教资格目录和教研室课表提交 / 共享 / 审批。
- 作业、文本教案、考试 CSV、学生记录和站内沟通等教学业务。
- SQLite v15 增量迁移、生产 TiDB 平移、Worker Secret、密码保护及故障边界。
- 无云凭据的空安装本地入口、首次注册管理员、隔离回归、公开 CI 和完整文档。

## 本地运行

```bash
git clone https://github.com/yanyu03/Sakura_DashBoard.git
cd Sakura_DashBoard
git checkout v1.0.0-sakura
npm ci
npm run dev
```

打开 `http://127.0.0.1:3000/?design=1.0Sakura` 并注册第一位管理员。没有共享管理员密码，也不需要连接作者的数据库或使用桌面凭据。

## 预览边界

登录仍为管理员 / 教师；尚未完成学生 / 家长独立产品、全模块多学校租户隔离、Key 报送、周模板 / 单双周 / 完整校历及容量 / 灾备验收。外部 AI、OCR 和家长实际消息投递未默认启用。TiDB HTTP 驱动的交互事务仍保留实验能力限制。

项目从 Google Stitch / AI Studio 原型演进，开发采用 AI 辅助。已有测试不构成全系统覆盖率或商用安全认证。此次文档与本地入口发布不自动重新部署作者的线上站点。
