# 安全更新与认证冷却

本次同步：v12 组织/身份/对象绑定元数据结构、停用所有账号的 SQLite 查询/状态/全库备份/重置 API、个人功能面板，以及 v13 持久化认证保护。原始数据库与旧业务记录保留。

注册和登录分别保护。每个账号每累计 5 次服务端认证失败（含验证码、凭据与注册校验错误），依次进入 30 秒、60 秒、120 秒、900 秒、10800 秒冷却；以后每满 5 次仍为 3 小时。冷却期间拒绝请求，不继续计数、不延长时间；冷却结束允许重试。成功登录清除该账号登录阶梯，成功注册清除该注册账号阶梯。

用户名、邮箱和手机号登录会解析为同一个内部账号桶；来源另有每 25 次错误触发保护的桶，10 分钟没有新错误且不在冷却时重置其计数。成功登录其他账号不能清除来源桶。Cloudflare 的边缘速率限制保留；本地不信任客户端伪造的 CF-Connecting-IP。保护桶以 SHA-256 标识写入 SQLite，返回 HTTP 429、Retry-After 和 retryAfterSeconds；前端显示等待倒计时。浏览器刷新、客户端改用户名或服务重启不清除账号保护。

迁移 v13 在事务中创建 auth_protection 和校验账本；本地迁移前自动备份，云端在 v11 基础上依次应用 v12、v13。云端旧版本、SQL 备份及其独立恢复验证、本地 SQLite 备份、Git bundle、未提交补丁和新增源码副本已保存在本机 `.local-data/security-release-backups/`，不提交 Git。

测试命令：`npm run test:protection`、`npm run test:auth`、`npm run test:hierarchy`、`npm run test:migrations`；结果在 `docs/verification/security/cooldowns.json` 等记录中。旧 SQL 工作台测试中期待任意查询与备份成功的断言已经不适用，不能当作新版权限验收。

限制：v12 只提供元数据基础。既有业务中的管理员跨账号放行、班级共享和完整 Key 双方授权流程尚未重构；本次加强认证与关闭数据库入口不代表已达到推广所需的用户数据隔离标准。root 首次注册与独立用户数据域也未随本次更新实现。
