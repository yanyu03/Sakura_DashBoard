# 1.0.1-sakura

Patch release for the 1.0Sakura application line.

- Makes the 1.0Sakura design the default when no design query parameter is supplied.
- Adds a shared application version source and a no-store version metadata endpoint.
- Shows the application and design-standard versions in the workspace and authentication portal.
- Does not change the API contract or the Cloudflare production deployment.
