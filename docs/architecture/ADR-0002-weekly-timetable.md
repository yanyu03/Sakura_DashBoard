# 学期周课表与日期课时

日期：2026-10-29。参考用户提供的 2026—2027 学年度第一学期授课总表，结构分析范围 Sheet1!A1:AT68。这里只记录结构与规则，不保存教师姓名，不将原始工作簿提交到仓库。

## 参考表的实际结构

表内有 62 个班：一年级 8、二年级 8、三年级 10、四至六年级各 12。每班周一到周五每天 6 节，共 1,860 个周课表格。F:AI 是周课表，AJ:AT 是跨行合并的学科任课安排，A:E 则包含班级及语数任课信息。合并单元格的教师不能简单复制成其覆盖区域每一个班的任课人；含班号范围的文字要先解析并确认。

这是小学样例，组织模型应支持不同学段，不能把年级写死为高中三年或小学六年。工作簿的显示范围外仍有格式，不能按 max_row=219、max_column=55 生成虚构班级。

原表包含音美轮换、地方课程中的心理健康、语文/自习中的书法、体育活动与地方/校本课程统筹使用。备注是规则来源，不应变成自动执行的脚本或数据库操作指令。表内没有节次起止时间、确切开学周一、节假日表和教室，不能凭标题日期或制表日期猜测这些信息。

## 数据层次

| 实体 | 保存内容 | 关键约束 |
| --- | --- | --- |
| 校历版本 | 学期、时区、第一教学周的周一、有效日期 | 明确确认周次锚点；制表日期不能替代开学日期 |
| 作息节次 | 校区 / 学段、节次编号、开始与结束时间、有效期 | 不写死每天 6 节；同一作息中节次不重叠 |
| 周课表版本 | 学校、学期、适用组织、修订号、草稿 / 待审 / 发布 / 替代 | 已发布版本保持历史；发布经过负责范围审核 |
| 周课表槽位 | 班级、星期、节次、单双周或指定周集合 | 同一班级、星期、节次在重叠适用周不能重复 |
| 槽位教学内容 | 课程、教学活动类别、主题、任课关系、共享场地 | 音美拆成两个适用周条目；书法是明确主题，不按换行猜第二个教师 |
| 校历例外 | 停课、补课、调休、借用其他星期课表 | 例外作用于具体日期，保留来源与审核人 |
| 日期课时 | 从已发布周模板和校历产生的实际开始 / 结束时间 | 记录来源版本与槽位；重复生成幂等，不能覆盖已审批调代课 |
| 导入批次与映射 | 文件哈希、表名、原坐标、原文、课程 / 班级 / 工号映射、待确认问题 | 先预览后确认；姓名不能直接创建或合并账号 |

既有 `schedule_entries` / `schedule_changes` 继续作为具体日期课时与调代课的事实，不把一整学期每个日期硬编码进周模板，也不因修改周模板抹去过去的审批记录。旧数据平移 TiDB 时保持原 ID，不要求为了增加周模板重新生成账号、班级或课时。

## 周规则与轮换

单双周以确认的教学周锚点计算。示例备注的规则是：一、二年级前四班单周音乐、双周美术，后四班相反。应明确保存班级集合、两项课程与奇偶周，不能只存 `音/美` 并依赖页面每次解释。

停课周是否计入单双周由校历确定；默认连续日历周计数，遇节假日不自动重置。调休课表应保存“实际日期 → 使用的教学日 / 周次”，从实际日期的上课时间检查冲突。

“体育活动与校本课程统筹”只说明可统筹的课程类别，不能自动删除课时、把不同课程视作同一课程或折算学时。需要在发布前明确具体安排及统计口径。

## 页面与流程

1. 班级周课表：按“星期 × 节次”展示，支持当前周、单周和双周。教师及负责人看到的范围仍来自有效任职和明确共享。
2. 教师周课表：同一日期 / 周次下合并其明确任课关系，标出跨班与校区安排；不通过姓名推断其他账号的任职。
3. 任课总表：按年级、班级、学科查看已确认任课关系，显示缺任课、多人共同授课、待确认导入项。
4. 发布检查：教师、班级、教室及共享场地冲突；重复或缺少槽位；无效任职与不匹配学科；单双周边界；课时统计差异。
5. 导入：只上传到有权限的学校，保留原始坐标，展示合并单元格和轮换解析结果；逐项确认账号 / 工号与课程映射，再生成可审核的草稿。未确认的信息不进入正式课表。
