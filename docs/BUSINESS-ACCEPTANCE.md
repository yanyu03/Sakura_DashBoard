# 1.0Sakura 本地业务验收

验收日期：2026-10-27。范围：单校教师端、管理员/教师两类账户、本地 Express + SQLite + React。当前为本地演示预览；数据真实落盘，外部服务未连接。

## 核心功能矩阵

| 入口 | 实际行为 | 验收与边界 |
| --- | --- | --- |
| 登录与偏好 | 校验密码和一次性验证码；Cookie 会话；偏好不能改账号凭据/角色 | 匿名 401、教师管理 403、跨班级拒绝、CSRF、验证码过期/复用、退出撤销；浏览器刷新/退出已验证 |
| 基础资料管理 | 建立/编辑学期、课程、教师、班级、学生、任教关系；归档保留原记录 | 双教师双班隔离；搜索分页；过期 version 返回 409；有在班学生时不能归档班级 |
| 作业批改中心 | 创建草稿、发布、登记正文、人工批阅、清除印章、范文、退回与重交、截止/归档 | 名单在发布时锁定；分数最多两位小数；未评分与 0 分分开；失败保留输入；截止后已退回的订正仍可登记 |
| 备课教案库 | 保存文本、标签与单元；私有/校内共享；版本历史；关联作业与课时 | 他人可读共享教案但不可编辑；私有教案不可越权；旧替换式写入接口已拒绝；归档不硬删 |
| 课表与排课 | 管理员建立具体日期课时；教师提出调代课；管理员批准/驳回；申请可撤销 | 提交不修改课表；申请人不得自批；同教师/班级/教室重叠拒绝；批准时复查冲突与源版本；提供 ICS |
| 考务与成绩 | 一班一课程考试、题目满分、CSV 模板/预览/确认导入、成绩导出 | 学号名单、重复行、分数范围校验；缺考/未评分/未录入区别；重复请求幂等；均分/分布/优秀/及格与样本一致 |
| 学生档案 | 实际名册、标签/简介、历史考试轨迹、辅导与关怀 | 统一学生 ID，不按姓名关联；删除了无真实来源的排名、雷达和考勤数字；当前页名单 CSV 明确最多 20 人 |
| 家校沟通 | 与档案共用联系人、会话、消息、辅导和待办 | 正文与摘要同事务；请求标识去重；未读可标记已读；当前为站内记录或待发送，不能宣称已送达 |
| 工作台/搜索/通知 | 读取真实模块数据；查询具体资源并定位；保存真实操作提醒与已读状态 | 教师只看到权限内数据；搜索不按关键词猜页面；免打扰按北京时间，当日开始时间至次日 08:00 延迟提醒 |
| 使用说明/SQLite 控制台 | 下载真实 MD 使用说明；读取实际表结构、迁移、计数与在线备份 | SQLite 管理仅管理员；默认只读 SQL；不再使用“试运行”按钮提交伪造账号或业务写入 |
| AI/外部连接 | 明确显示未连接，调用未配置 AI 会失败 | 无模拟分析、假评分、付费请求或对外消息；没有进行供应商/凭据配置 |

## 浏览器完整故事

写入操作均在隔离浏览器数据库进行；3000 端口原预览只验证升级、读取与登录。

1. 创建“浏览器验收：写作练习”并发布，登记正文，保存 92.5 分及批注；待批变为 0、均分 92.50，刷新仍可读。[截图](verification/business/homework-workflow.png)
2. 新建文本教案、重新打开编辑并保存第二版；接口验证作者权限、私有/共享、历史版本与关联。
3. 建立 2026-10-28 09:00—09:45 的实际课时；页面与数据库记录一致。修复了日期显示有值但提交读取不到的问题。[截图](verification/business/schedule-workflow.png)
4. 建立考试，粘贴 CSV，校验预览后确认导入 88.5；均分显示 88.50，学生档案出现同一考试记录。[截图](verification/business/exam-workflow.png)
5. 下载实际成绩 CSV，核对学号、姓名与 88.5 分。[下载文件留存](verification/business/exported-exam-results.csv)
6. 在学生档案添加联系人并保存一条站内备注，切换家校页仍读取同一会话及正文。[截图](verification/business/care-workflow.png)
7. 全局搜索“浏览器验收”，返回实际教案与作业；点击作业定位到对应班级和作业 ID。
8. 检查 1280×720、390×844 以及用户原 435×668 视口；手机导航、抽屉和滚动可用。检查午夜青蓝主题并修复次级按钮对比度。[手机截图](verification/business/mobile-overview.png)、[暗色截图](verification/business/dark-overview.png)

## 本轮限制

- 未做生产部署或学校真实数据上线验收，未推送 GitHub；演示库的已存在样本仍为样本。
- 新课表采用实际日期。旧周次课表、固定考试结论与旧家校示例留存在原表，未猜测新关系后自动迁入。
- 作业支持教师手工登记文本；教案仅文本。文件附件、OCR、PDF、成对互换两个课时、多科综合报表不在本轮交付内。
- AI、家长端/短信投递、扫码/短信登录、外部日历同步和投屏设备未连接。待发送记录不会自动变成已送达；免打扰只控制站内提醒可处理时间。
- 普通归档入口隐藏资料并保留历史；管理员可核查原记录。尚无统一的归档恢复/回收站页面。
- 目前为管理员/教师权限，未实现学生端、家长端、多学校租户、完整审计报表或密码自助找回。

这些限制均不使用 Toast 或固定结果伪装完成。后续接外部提供方时，应单独明确凭据、传输数据和费用范围。
