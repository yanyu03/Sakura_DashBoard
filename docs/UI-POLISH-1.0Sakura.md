# 1.0Sakura 外观优化记录

日期：2026-10-27。范围：工作台与作业、教案、课表、成绩、学生档案、家校记录的展示层。保留现有业务接口和数据库逻辑。

## 外观调整

- 使用标准的 canvas/card/muted/accent/glass 背景变量，增加轻量点阵底纹、柔和渐变、白板面板和层次阴影。
- 增加统一页头、原生 SVG 书页插画、图标、快捷入口、统计卡片、日程和关怀空状态。
- 为教案增加封面区，编辑区可展开；学生档案增加身份区，批阅名单增加姓名头像，卷面保留清晰阅读背景。
- 控件、内容卡片、主页头分别沿用标准圆角。浏览器实测卡片 12px、页头 16px。
- 沿用 `sakura-rise-in` 与标准缓动/时长：入场 240ms，展开与悬停提供轻量反馈。减少动态效果模式会关闭动画、过渡与悬停位移。
- 修复桌面业务区原有 `overflow-hidden` 裁切长内容的问题；手机保留双列统计、触控尺寸与底部导航。

## 实现位置

- `src/styles/workspace-polish.css`：独立的产品展示层，引用标准令牌，不改写标准 MD/CSS 的对应关系。
- `src/components/WorkspaceVisuals.tsx`：页头、章节标题与空状态组件。
- 工作台及相关业务视图只调整布局、文案与展示元素。

## 验证

- TypeScript 检查、Vite 生产构建、CSS/MD 标准一致性校验均通过。
- 检查 1280×800 桌面与 390×844 手机布局，并验证午夜青蓝主题；已恢复抹茶森林。
- 浏览器计算样式：页头圆角 16px、卡片圆角 12px、入场动画 `sakura-rise-in`、时长 0.24s；桌面无页面横向溢出。
- 实测教案编辑区展开后可输入；批阅页能滚动到下方卷面与评分区。此次界面检查未提交新的业务记录。
